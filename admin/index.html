Базу ще не підключено

Приватна частина зберігає документи у Firestore (Google Cloud). Залишилось один раз налаштувати Firebase:

  1. Створіть проєкт на console.firebase.google.com і додайте Web app.
  2. Увімкніть Authentication → Google та Firestore Database.
  3. У Authentication → Settings → Authorized domains додайте sergii21.github.io.
  4. Вставте конфіг у assets/firebase-config.js і запуште.

Покрокова інструкція — у README репозиторію.

Кабінет власника

Документація та керування проєктами. Доступ лише для власника компанії.

Немає доступу

Цей акаунт не є власником. Якщо це ви налаштовуєте сайт уперше — скопіюйте свій UID у правила Firestore (рядок OWNER_UID у firestore.rules) і опублікуйте їх у Firebase Console.

Ці записи бачать усі відвідувачі сайту в розділі «Проєкти».
